# AKI IRIAM立ち絵 制作基準書

更新日: 2026-09-07  
適用範囲: AKIのIRIAM用全身立ち絵・衣装差分・頭部置換・局所修正

## 1. AKIが最終的に望むもの

AKI本人の正式な顔と髪を、衣装やポーズが変わっても同一人物として100%維持した、プロ品質の全身立ち絵を作る。

優先順位は次のとおり。

1. 顔
2. 髪型・左右の襟足
3. 頭部と首・胴体の自然な接続
4. ポージング・等身・身体バランス
5. 衣装・小物の完全保持
6. 画質・解像度・背景・余白

「似ている」では不十分。顔と髪は再生成して近づけるのではなく、正式頭部マスターの画素を固定資産として使用する。

## 2. 絶対固定資産

### 正式頭部マスター

- 顔・髪・耳・ピアス・表情を一体の固定資産として扱う。
- 再生成、似せ描き、補完、再設計、顔だけの変形は禁止。
- 許可される操作は、頭部全体の均等倍率変更とX/Y移動のみ。
- 顔のみの拡大・縮小、縦横別倍率、ワープは禁止。
- 代替頭部マスターや「マスター2」は別系統の候補として管理し、AKIの明示的決定なしに正式マスターへ置き換えない。

### 全身マスター

次を固定する。

- 成人男性の自然な約7等身
- 垂直姿勢、正面カメラ、通常の目線
- 頭の位置・肩幅・首の長さ・胴体・脚・足先
- 衣装、ポーズ、マグカップ、持ち手、手指
- 白いくま、ローブ、チェックのパンツ
- リボン、星、月、ポンポン、AKI表記
- くまスリッパ
- 白背景

## 3. 顔の固定基準

固定対象:

- 顔の輪郭と横幅
- 青い目の形、横幅、目尻、左右間隔
- 眉、鼻、顎
- 目から口までの短い距離
- 正面の自然な開口笑顔
- 口の形と口角
- 年齢感
- 顔の傾き0
- 右耳ピアス

禁止:

- 面長
- 細い目
- 顎を尖らせすぎる
- 顔の傾き
- ぼんやりした甘い顔
- 子供っぽい顔
- 生成による別人化
- 顔表面のノイズ、茶色い線、グレーのシミ

## 4. 髪型の固定基準

### 全体形

- 上部が広く、首元へ細くなる「逆さ卵」型。
- 重力に沿う下向き・内向きの流れを主体にする。
- 太い面の毛束を維持する。
- 丸型、ひし形、ヘルメット型、ライオンのたてがみ状は禁止。
- 耳周辺の横膨張、細かな外ハネの大量追加は禁止。

### 左右の定義

この文書の左右は、すべて「画像を見た人から見た左右」で記録する。

### 向かって左側

- マスターにある長い襟足を毛先まで保持する。
- 途中で水平・垂直に切らない。
- 毛先は自然に細く尖って終わる。
- 長さ、太さ、終点、外→内の流れをマスターと合わせる。
- 外ハネはさりげないアクセントに限定し、全体は内向きに収束させる。

### 向かって右側

- マスターどおり内ハネを主体にする。
- 耳横・耳下・襟足へ余分な外ハネを加えない。
- 長さ、細さ、毛先の終点をマスターと合わせる。
- 首線や旧髪と重なって二重線に見えないようにする。

## 5. 出力仕様

- 最終納品: 1980 × 2970 px
- 比率: 縦2:3
- 形式: PNG
- カラーモード: RGBまたはRGBA
- 背景: 白
- 全身と両足先を完全表示
- 上部の白余白: 約12 px
- 人物を不必要に縮小・変形して余白を作らない
- マットでノイズなし

1024 × 1536 pxは生成途中のプレビュー・検証用に限る。最終成果物として渡さない。1980 × 2970へ単純拡大しただけでぼやける出力も不可。

## 6. 標準制作工程

### A. 新しい衣装・新しい1×4候補

1. 毎回、正式頭部マスターと正式全身マスターの2枚だけから開始する。
2. 過去候補・過去修正版を次回の生成元にしない。
3. 全身マスターを基礎レイヤーにする。
4. 旧頭部・旧髪を精密マスクで除去する。
5. 正式頭部マスターを均等倍率で配置する。
6. 顎中央、首中央、鎖骨中央、衣装中央、胴体軸を合わせる。
7. 首・襟との接続は顎下のごく狭い範囲だけ処理する。
8. マグカップ、持ち手、指、襟、ローブ前縁を前面レイヤーとして復元する。
9. 1980 × 2970キャンバス上で最終合成・確認する。
10. 4枚を別々の独立ファイルとして保存する。

1×4とは、1枚の比較シートに4人を並べる意味ではない。AKIひとりの画像を4枚、独立画像・独立ファイルとして作る。

4候補の差は原則として以下だけに限定する。

- 頭部全体の均等倍率
- X位置
- Y位置
- 首元の狭い接続処理

顔、髪、衣装、小物を候補ごとに描き変えない。

### B. 成功パターン確立のための1体制作

AKIが「一体のみ」と指定した場合は、4枚を作らず1体だけを制作する。顔・首・襟足の接続が合格してから1×4へ戻す。

### C. 特定候補の局所修正

AKIが「この顔・身体バランスを完全に維持し、この箇所だけ直す」と明示した場合のみ、その指定候補を不変の土台として使用できる。

この場合:

1. 指定候補を直接の固定土台にする。
2. 修正範囲を1〜数px単位のマスクで限定する。
3. 顔、衣装、対象外の髪は変更しない。
4. 変更前後のピクセル差分と変更範囲を記録する。
5. 修正範囲外の差分が0pxであることを確認する。
6. 元候補を上書き・削除しない。

この例外を、新規候補制作の反復編集へ流用してはいけない。

## 7. 首・顎・襟の接続ルール

- 顎線は正式頭部マスターの線を保持する。
- 顎の下へグレーの帯状面を作らない。
- 首の付け根へ茶色い縦線を残さない。
- 左右どちらにも二重首線を残さない。
- 頭部と胴体の中心をずらさない。
- 首を長くしすぎない、短くしすぎない。
- 頭が浮いて見える接続は禁止。
- 襟を片側だけ不自然に持ち上げない。
- 首周りの衣装形状は全身マスターを基準にする。
- 旧頭部・旧髪・旧首の画素を新しい頭部の下へ残さない。
- 白い四角、水平線、切り抜き境界、ぼかし帯を残さない。

生成によるなじませ処理を使う場合も、顎下から首・襟へのごく狭い範囲だけに限定する。顔、髪、ピアス、衣装、小物へ広げない。

## 8. レイヤー順

推奨順序:

1. 白背景
2. 正式全身マスター
3. 旧頭部除去後の清掃済み首下地
4. 正式頭部マスター
5. 顎下〜首の限定接続
6. マグカップ、持ち手、手指
7. 襟、ローブ前縁、肩周りの前面要素
8. 最終局所修正

背景除去マスクでマグカップ、手、襟、肩、胸元を覆わない。

## 9. 毎回の検査

400〜800%に拡大し、1〜数px単位で次を確認する。

- 顔と髪が正式頭部マスターと一致
- 目・眉・鼻・口・顎・輪郭の固定
- 頭部サイズと約7等身
- 頭幅と肩幅の比率
- 顎・首・肩・鎖骨・胴体中心
- 向かって左側の長い襟足と毛先
- 向かって右側の内ハネと襟足
- ライオン現象・横膨張・追加外ハネの有無
- グレーの帯、茶線、二重首線、シミの有無
- 左右の襟、ローブ前縁
- マグカップ全体、持ち手、手指
- 白いくま、装飾、パンツ、スリッパ
- 全身と両足先
- 上部余白約12px
- 白い四角、水平線、切り抜き境界、欠損
- 1980 × 2970 px PNGであること
- 保存後にPNGを最後まで読み戻せること

欠損や不自然な合成が1つでもある画像を「合格」と報告しない。

## 10. 報告形式

候補ごとに最低限、次を表で報告する。

| 項目 | 内容 |
|---|---|
| ファイル | 独立画像へのリンク |
| 頭部調整 | 倍率、X/Y位置の差 |
| 顔・髪固定 | 合格／不合格 |
| 首・襟足 | 合格／不合格と差異 |
| 衣装・小物 | 欠損の有無 |
| 解像度 | 実測値 |
| 総合判定 | 合格／不合格 |

最良候補を示すことはできるが、AKIの明示的決定なしに正式マスターへ昇格させない。

## 11. 保存・版管理

- 原本画像と完成PNGはChatGPT Libraryにも保持する。
- GitHubには仕様、解析、座標、ハッシュ、工程、検査結果を保存する。
- 必要に応じて候補画像も、正式マスターと混同しない候補用ディレクトリへ保存する。
- 過去画像を上書き・削除しない。
- 日付、候補番号、版番号、解像度が分かる名前にする。
- 正式マスターと候補を明確に分離する。
- 各ファイルのSHA-256を記録する。
- 正式昇格にはAKI本人の明示的承認が必要。

## 12. 作業前コミュニケーション

AKIが「まだ画像生成しない。まず返答」と指定した場合、画像生成・画像編集を開始しない。問題点、原因、修正方法、固定範囲を先に言葉で確認する。

「お願いします」「では作って」など、明確な開始許可が出てから制作を開始する。

## 13. 過去に発生した失敗と再発防止

| 失敗 | 主因 | 再発防止 |
|---|---|---|
| 1024×1536で納品 | 生成サイズを最終仕様と誤認 | 最後に実測し、1980×2970以外は納品しない |
| 顔が別人・甘い | 顔を再生成 | 正式頭部の画素置換のみ |
| ライオン髪 | 耳周辺の生成・外ハネ追加 | 逆さ卵型と内向きの太い毛束を固定 |
| 左襟足の先端切れ | 保護マスクが毛先前で終了 | マスター毛先より外までマスクを確保し800%確認 |
| 首の二重線 | 旧首線と新頭部の線が共存 | 旧線を限定除去後、正しい髪と首を配置 |
| 顎下のグレー帯 | 頭部側の首影と全身側の首を重ねた | 顎線より下を全身側へ戻し、狭い境界だけ接続 |
| 首・胴体のずれ | 顔中心だけで配置 | 顎・首・鎖骨・衣装・胴体の5軸照合 |
| 片襟が上がる | 頭部マスクが襟へ侵入 | 襟とローブ前縁を前面レイヤーで復元 |
| コップや手が消える | 頭部消去マスクが小物へ侵入 | 小物保護レイヤーを最後に復元 |
| PNG破損・末尾欠損 | 書き出し完了前の扱い | 保存後にverifyと全画素loadを実行 |

## 14. 完成の定義

AIが独自に「完成」と決めない。

完成とは、全検査に合格した候補をAKI本人が確認し、明示的に正式マスターとして選んだ状態を指す。
