# AKI IRIAM立ち絵 毎回のQAチェックリスト

このチェックリストは、1体制作・1×4制作・局所修正のすべてで使用する。

## 制作前

- [ ] AKIから画像生成・編集の開始許可が出ている
- [ ] 使用する正式頭部マスターを特定した
- [ ] 使用する正式全身マスターを特定した
- [ ] 過去候補を誤って新規制作の生成元にしていない
- [ ] 今回が新規制作か、AKI指定候補の局所修正かを区別した
- [ ] 左右を「画像を見る側」で統一した
- [ ] 出力を1980 × 2970 px PNGに設定した

## 顔・頭部

- [ ] 顔を再生成していない
- [ ] 頭部全体だけを均等倍率で調整した
- [ ] 顔の輪郭・横幅が一致
- [ ] 青い目の形・横幅・間隔・目尻が一致
- [ ] 眉・鼻・口・顎・開口笑顔が一致
- [ ] 顔が傾いていない
- [ ] 面長・巨大顔・子供顔になっていない
- [ ] 耳・ピアスが一致
- [ ] 顔表面にノイズ・茶線・グレーのシミがない

## 髪

- [ ] 逆さ卵型の外周を維持
- [ ] 耳周辺が横膨張していない
- [ ] ライオンのたてがみ状になっていない
- [ ] 太い面の毛束を維持
- [ ] 毛流れが下向き・内向き
- [ ] 向かって左側の長い襟足が毛先まで残っている
- [ ] 左襟足の先端が途中で切れていない
- [ ] 向かって右側の内ハネと短い襟足が一致
- [ ] 左右に余分な外ハネを追加していない
- [ ] 旧髪が下から見えていない

## 頭身・姿勢

- [ ] 成人男性の自然な約7等身
- [ ] 頭が大きく見えない
- [ ] 頭幅と肩幅の比率が自然
- [ ] 顎から鎖骨までの距離が自然
- [ ] 首が長すぎず短すぎない
- [ ] 顎・首・鎖骨・衣装・胴体の中心軸が一致
- [ ] 垂直姿勢・正面カメラ
- [ ] のけぞり・ローアングル・ガニ股がない

## 首・襟・合成境界

- [ ] 向かって左右の首線が胴体へ自然につながる
- [ ] 二重首線がない
- [ ] 顎下にグレーの帯がない
- [ ] 首の付け根に茶色い縦線がない
- [ ] 顎線が乱れていない
- [ ] 頭が浮いて見えない
- [ ] 左右の襟が全身マスターどおり
- [ ] 片側の襟が不自然に上がっていない
- [ ] 白い四角・水平線・ぼかし帯・切り抜き境界がない

## 衣装・小物

- [ ] マグカップ全体がある
- [ ] カップの持ち手がある
- [ ] 指・手に欠損がない
- [ ] 白いくまが完全表示
- [ ] ローブ・前縁・ファーが保持
- [ ] チェックのパンツが保持
- [ ] 星・月・リボン・ポンポン・AKI表記が保持
- [ ] くまスリッパと両足先が完全表示

## ピクセルQA

- [ ] 100%表示で全身を確認
- [ ] 400%表示で顔・首・襟足を確認
- [ ] 800%表示で線・毛先・境界を確認
- [ ] 局所修正は1〜数px単位のマスクに限定
- [ ] 修正範囲外の差分が0px
- [ ] 顔保護範囲の差分が0px
- [ ] 衣装・小物保護範囲の差分が0px
- [ ] 変更ピクセル数と変更bboxを記録

## ファイルQA

- [ ] 実測1980 × 2970 px
- [ ] PNG
- [ ] RGBまたはRGBA
- [ ] 白背景
- [ ] 上部余白約12px
- [ ] 頭頂から両足先まで完全表示
- [ ] 保存後にPNG verify成功
- [ ] 保存後に全画素load成功
- [ ] SHA-256を記録
- [ ] 過去候補を上書きしていない
- [ ] 正式マスターと候補を別管理

## 報告

- [ ] 候補ごとのリンクを提示
- [ ] 倍率・X/Y位置・差異を記載
- [ ] 不具合がある候補を合格と報告していない
- [ ] 最良候補を示しても正式昇格していない
- [ ] AKI本人へ最終判断を委ねた
