# 正式頭部ピクセル置換フロー

## 基本原則
- 毎回、元の約90%完成全身マスターから開始する。
- 過去の修正版・生成候補を次の素材にしない。
- 正式頭部マスターのRGBA/ピクセル資産を読み込む。
- AIで顔・髪を再生成せず、そのまま合成する。

## 調整してよい項目
1. 頭部スケール
2. X位置
3. Y位置
4. 首中心との整列
5. 襟・首境界のごく狭い接続部

## 固定する項目
ボディ、衣装、ポーズ、構図、持ち物、背景、等身、肩幅、胴体、脚長、人物サイズ、カメラ距離。

## 初回ピクセル置換テスト記録
- body source: 1024×1536
- replacement crop: `(20, 0, 1555, 1450)`
- first test target width: 258 px
- first test target height: 244 px
- first test placement: `(x=385, y=7)`
- 判定: 頭部そのものの再現には成功。残課題は頭部位置・ボディ中心・首接続。

## 禁止
- 「似せる」ための再生成
- A→A2→A3の反復編集
- 顔・髪の描き直し
- 体型・肩幅・脚・衣装・小物の副次変更
- 広範囲の白塗りで旧頭部を消す処理

## 合成品質
旧頭部領域は可能な限り精密なマスクで除去し、正式頭部を重ねる。首接続の補正は狭い境界に限定し、ボディ原本のピクセルを守る。完成判定はAKI本人が行う。
